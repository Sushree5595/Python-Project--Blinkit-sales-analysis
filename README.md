## 🛒 Blinkit Sales Analysis using Python

#### 📌 Project Overview

This project analyzes Blinkit sales data to uncover insights into product sales, outlet performance, and customer preferences. Using Python’s data analysis libraries, the project processes raw data, performs exploratory data analysis (EDA), and extracts actionable insights.

The analysis highlights sales distribution, item categories, outlet size/type impact, and customer ratings to help businesses make data-driven decisions.

#### 🔧 Tools & Libraries Used

Python 🐍

Pandas & NumPy – Data cleaning & manipulation

Matplotlib & Seaborn – Data visualization

Jupyter Notebook – Interactive development

#### 📊 Key Insights from the Analysis

Total Sales: $1,201,681.5

Average Sales per Item: $141.0

Total Items Sold: 8,523

Average Customer Rating: 3.97 / 5

pip install -r requirements.txt
